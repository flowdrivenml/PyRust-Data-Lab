# Firefox

Use Firefox DevTools to understand the site, Playwright Inspector to experiment with automation, and Jupyter to keep a live session and query it.
In the browser, open DevTools with F12:
- Inspector shows the current DOM. Select a control and see its tag, attributes, text, and parents.
- Network shows what the page requests. Reload, then filter for document, Fetch, and XHR requests. Open a dropdown or select a market and watch what new requests appear.
- Console shows page errors and JavaScript messages.
