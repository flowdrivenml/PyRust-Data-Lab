## Why I Use Stylus

I spend a lot of time in a browser, but websites often have colors and layouts that do not match my taste. I use **Stylus** to customize how sites look, so I can make them fit my Tokyo Night style and feel more comfortable to use.

Stylus is a browser extension for applying custom CSS to websites. It changes how a page looks in my browser without changing the website itself. I use it to style sites such as ChatGPT, GitHub, Gmail, and YouTube, as well as to set a general appearance for other pages.

## Install Stylus

Install Stylus from the extension store for your browser:

- [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/styl-us/)
- [Chrome Web Store](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne)
- [Stylus source code on GitHub](https://github.com/openstyles/stylus)

After installing it, pin the Stylus icon to the browser toolbar so the styles are easy to manage.

## Use a Website Style

A quick way to start is to find a user style made for a site you use. You can install compatible UserCSS styles from their source, then enable or disable them through Stylus. Check that a style is intended for the correct website and review its source before installing it, since community styles can become outdated when a website changes.

For sites I use often, I keep dedicated styles for ChatGPT, GitHub, Gmail, and YouTube. I also use a general style where it works well across other websites.

## Customize a Website Yourself

Stylus includes an editor for writing or adjusting CSS. Open the extension on the website you want to change, create a style for that site, and add CSS rules for the parts you want to customize. For example, you can change colors, backgrounds, fonts, borders, and spacing.

Website layouts change over time, so a custom style may need occasional fixes. I keep changes focused on appearance and test them on the actual site after editing.

## Keep Styles Organized

I keep my Stylus CSS configurations in the `configs/stylus/` folder. This keeps browser styling files together and makes them easier to back up, reuse, or adjust later. I organize styles for ChatGPT, GitHub, Gmail, YouTube, and a general style for other websites.

Stylus is a small way to make a browser I use every day feel more personal and consistent with my desktop and development tools.
